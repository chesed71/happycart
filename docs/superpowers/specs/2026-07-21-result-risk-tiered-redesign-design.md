# 결과 화면 위험도 단계별 리디자인 (result.html 반영)

- 날짜: 2026-07-21
- 대상: `happycart/lib/features/result/result_page.dart` (Success 레이아웃)
- 참조 디자인: Open Design `screens/result.html`

## 배경 / 목표

현재 결과 화면은 판정을 `okay` / `notOkay` 두 단계로만 표현하고, `notOkay`는
"잠깐" 빨강 톤 하나로 고정된다. 새 디자인은 `notOkay`를 **제품 대표 위험도**에
따라 낮음/중간/높음 3단계로 시각화하고, 위험도 게이지와 안내 배너를 더한다.

최근 추가한 성분 카드의 좌측 컬러바·위험도 배지는 **그대로 유지**한다. 펼침
영역은 이유와 건강 근거·출처(라벨 없이 한 줄 병기)만 두고, 개발용 RULE 표시는
두지 않는다. 즉 이 작업은 "기존 기능 위에 새 시각 요소를 얹는" 방향이다.

## 상태 모델

화면 상태를 네 가지로 확장한다: `ok` / `low` / `medium` / `high`.

- `okay` → `ok` : 기존 초록 "괜찮아요" 화면을 그대로 둔다(게이지·배너 없음).
- `notOkay` → 성분 중 **최고 위험도**로 결정한다. `buildRiskDisplayList`가 이미
  위험도 높은 순으로 정렬하므로, 결과의 첫 성분 `riskLevel`을 대표 위험도로
  사용한다. 대표 위험도를 특정할 수 없을 때(riskLevel 전부 null 등)는 방어적으로
  중간(medium)으로 취급한다.

## 히어로 (단계별 톤)

배경 그라디언트, "잠깐" 글자색, 카트·손 마크 색을 대표 위험도에 따라 분기한다.

- 카트·손 마크는 흰 원형 배지 위에 놓인다. 낮음=노랑, 중간=주황, 높음=빨강.
  제품 이미지 중앙 슬롯은 `괜찮아요`(ok)에서만 노출한다. `잠깐`(낮음·중간·높음)
  단계에서는 상품 사진을 감추고 카트·손 마크만 보여준다.
- 배경 그라디언트 상단색: 낮음 `#FBF1CF`, 중간 `#FCE8D2`, 높음 `#FCE3DE`
  (하단은 공통 `#FCFBF8`).

## 위험도 게이지 (신규)

"잠깐" 글자 아래, 제품명 pill 위에 배치한다.

- 3칸 막대. 낮음=1칸, 중간=2칸, 높음=3칸을 단계 색으로 채우고 나머지는 회색
  (`#E9DECB`).
- 오른쪽에 "위험도 **[단계]**" 라벨. `ok` 상태에서는 게이지를 숨긴다.

## 안내 배너 (신규)

성분 목록 **위**에 배치한다(안내를 먼저 보고 성분을 확인하는 흐름).

- 단계 색 배경 + 정보 아이콘 + 단계별 문구. 배경/글자색은 단계 soft/deep 색을
  사용한다.

## 성분 카드 (기존 유지)

좌측 컬러바·위험도 배지·펼침 영역(이유 + 건강 근거·출처 한 줄 병기)을 현행 그대로
둔다. 개발용 RULE 표시는 두지 않는다. 이번 작업에서 성분 카드 내부 구조는
건드리지 않는다.

## 색 팔레트 (AppTheme 추가)

- 낮음: main `#E1A50B`, deep `#8A6300`, soft `#FBEFC9`
- 중간: main `#EE7A1A`, deep `#A85400`, soft `#FCE7D0`
- 높음: 기존 stop 계열(`AppTheme.stopMain`/`stopDeep`/`stopSoft`) 재사용

## 에셋

- `cart_stop.png`·`hand_stop.png`를 색조 변경해 `cart_low`·`cart_med`·`hand_low`·
  `hand_med`를 생성한다. 카트는 균일 단색이라 목표색으로 전면 치환, 손은 빨강
  금지원만 목표색으로 바꾸고 회색 손·얼굴은 유지한다.
- 재현용 스크립트를 `happycart/tool/`에 보관하고, 결과 PNG는
  `assets/verdict/`에 추가한 뒤 `pubspec.yaml`에 등록한다.
- 검증 완료: 노랑도 흰 배지 위에서 대비 충분, 손 회색 유지, 3단계 색 구분 명확.

## 문구

- 히어로 sub 문구는 두지 않는다(안내 배너와 중복되어, 게이지 아래 바로 제품명
  pill로 이어진다).
- 안내 배너 문구
  - 낮음: "낮은 위험이에요. 대부분 안전하지만, 자주 드신다면 아래 성분만 가볍게 확인해보세요."
  - 중간: "용량 의존형 위험이에요. 가끔·적당량이면 괜찮지만, 자주·많이 드시는 건 피하세요."
  - 높음: "높은 위험이에요. 안전한 섭취 구간이 없어, 되도록 피하는 걸 권해요."
- 게이지 라벨: "위험도 낮음 / 위험도 중간 / 위험도 높음"

## 비범위 (YAGNI)

- HTML의 "깨끗한 성분(clean-card)" 섹션은 데이터 소스가 없어 이번 범위에서 제외.
- `ok`(괜찮아요) 화면은 기존 그대로 — 시각 변경 없음.
- 대표 위험도 계산은 "최고 위험도 성분" 단순 규칙만 사용(가중치·개수 규칙 없음).

## 테스트

- 위젯 테스트: 대표 위험도별 화면 상태(low/medium/high) 결정, 게이지 채움 칸수,
  단계별 배너 문구, 히어로 마크 에셋 경로 선택.
- 기존 성분 카드 테스트(정렬·배지·컬러바·건강 근거·출처)는 유지하고 계속
  통과해야 한다.
